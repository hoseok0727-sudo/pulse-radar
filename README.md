# Pulse Radar

Published reader at https://hoseok0727-sudo.github.io/pulse-radar/

This repository contains only browser assets and public source metadata. Interests and reading history stay in each visitor’s browser. Optional AI summaries use the visitor’s own OpenRouter account after an explicit request. No operator workspace, account database, credentials or draft videos are deployed.

Daily editorial production runs separately; pushing a reviewed public bundle updates GitHub Pages.
